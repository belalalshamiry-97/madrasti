# 🎓 مدرستي — Madrasti School LMS

> **منصة التعلّم الإلكتروني المتكاملة للمرحلة الثانوية**
> تم تطويرها وفق أحدث المعايير البرمجية كمنصة إنتاجية حقيقية متكاملة لمدرسة ثانوية واحدة، مخصصة لمدير المدرسة والمعلمين والطلاب.

---

## 🌟 أبرز مميزات المنصة

- 🎨 **تصميم واجهات داكن احترافي (Dark Theme by Default):**
  - مطابقة دقيقة لألوان الهوية: الخلفية الأساسية (`#0F172A`)، البطاقات (`#1E293B`)، السطوح (`#243449`)، اللمسة الزرقاء السماوية (`#38BDF8`)، ولمسة النجاح الفيروزية (`#2CB6A3`).
  - دعم أصيل للغة العربية والاتجاه من اليمين لليسار (`dir="rtl"`) مع خط القاهرة (Cairo).
- 🛡️ **عزل إداري صارم (Strict Role-Based Admin Isolation):**
  - لوحة تحكم الإدارة (`/admin`) ومساراتها محمية برمجياً عبر Middleware ولا تظهر أو يمكن الوصول إليها نهائياً إلا للمستخدمين ذوي دور `ADMIN`.
- 📚 **الهيكل الأكاديمي للثانوية العامة:**
  - تغطية صفوف المرحلة الثانوية (أول ثانوي، ثاني ثانوي، ثالث ثانوي) بمساراتها (عام، علمي، أدبي).
- 📝 **نظام الواجبات والتصحيح الشامل:**
  - دعم تسليم الواجبات النصية ورفع الملفات مع ميزة **تصوير صفحات الدفتر مباشرة بكاميرا الهاتف**.
  - طابور تصحيح المعلم مع عارض الملفات المدمج ورصد الدرجات وكتابة التغذية الراجعة.
- ⏱️ **محرك الاختبارات الإلكترونية الموقوتة:**
  - مؤقت تنازلي لحظي، تصحيح تلقائي لأسئلة الاختيار من متعدد والصح/خطأ، وعرض النتيجة والشرح النموذجي فور التسليم.
- 📋 **التحضير والغياب الذكي:**
  - كشف حضور يومي بنقرة واحدة (حاضر، غائب، متأخر، بعذر) مع تقارير التزام الطالب.
- 💬 **منظومة التواصل والإشعارات المباشرة:**
  - رسائل ثنائية آمنة بين المعلم وطلابه، إعلانات مدرسية موجهة، ومناقشات داخل صفحة الدرس.
- 📱 **دعم تطبيق الويب التقدمي (PWA & Offline):**
  - يدعم التثبيت على شاشات الهواتف كأنه تطبيق أصلي، مع كاش Service Worker وصفحة مخصصة للعمل دون إنترنت.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend & Framework:** Next.js 15 (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS, Lucide Icons, Cairo Font
- **Backend & Database:** Supabase (PostgreSQL 33 Tables, Row-Level Security, Storage Buckets, Triggers)
- **Deployment & Architecture:** Vercel Edge / Serverless, PWA Service Worker

---

## 🚀 التشغيل المحلي (Getting Started)

1. **تثبيت الاعتماديات:**
   ```bash
   npm install
   ```

2. **ضبط المتغيرات البيئية:**
   ```bash
   cp .env.example .env.local
   ```

3. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```
   افتح المتصفح على [http://localhost:3000](http://localhost:3000).

4. **بناء نسخة الإنتاج:**
   ```bash
   npm run build
   npm start
   ```

## 📁 هيكلية المشروع

```text
madrasti/
├── public/                 # ملفات الـ PWA، الأيقونات، و sw.js
├── src/
│   ├── app/                # مسارات Next.js 15 App Router
│   │   ├── (auth)/         # تسجيل الدخول

│   │   ├── announcements/  # الإعلانات المدرسية
│   │   ├── messages/       # المحادثات والرسائل
│   │   ├── notifications/  # مركز الإشعارات والتنبيهات
│   │   ├── offline/        # صفحة العمل دون اتصال
│   │   ├── student/        # المقررات، الواجبات، الاختبارات، الحضور، الدرجات
│   │   └── teacher/        # إضافة الدروس، الواجبات، التصحيح، التحضير، الاختبارات

├── DEPLOYMENT.md           # دليل النشر والربط السحابي
├── BACKUP_RECOVERY.md      # خطة النسخ الاحتياطي والتعافي
└── USER_GUIDE.md           # دليل المستخدم الشامل
```
